# Hyunjoo's Home Page

The editable site is in [`hyunjoo-home/`](hyunjoo-home/). Run `npm run dev` from this repository root to preview it locally.

The root `index.html` opens the site at `hyunjoo-home/` so GitHub Pages can serve the project from the repository root. In the repository's **Settings → Pages**, select **Deploy from a branch**, `main`, and `/(root)`.

Edit files in `hyunjoo-home/` and commit those changes to update the GitHub Pages site. The nested `dist/` folder is a local build output and is not required by GitHub Pages.

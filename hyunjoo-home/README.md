# Hyunjoo's Home Page

Edit these files to change the site:

- `index.html` — words and page structure
- `style.css` — colors, fonts, layout, and animation
- `script.js` — button behavior
- `assets/` — optional images and GIFs

From this folder, run `npm run dev` and open the local URL printed in the terminal. The same command also works from the parent `hyunjoo's homepage` folder. Refresh the browser after saving a change.

Run `npm run build` to copy the editable source into `dist/` for publishing. Avoid editing `dist/` directly because each build replaces it.

The first Interactive project is published from `projects/track-to-move/`. Its original source is the sibling `5주차과제_invert box` folder. The published copy contains the GA4 tag and example lifecycle events; preserve those when updating the project.

The second and third Interactive projects are published from `projects/thumbs-up-to-click/` and `projects/balloon-face/`. Their original sources are the sibling `ThreeThumbsUp/dist` and `4주차과제_BalloonFace` folders. The published copies start the camera experience on page load and include GA4 events; preserve those additions when refreshing the copies.
